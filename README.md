🔮 <답 말고 식 찾기> 매직믹서 수학 수업 도구

법동중학교 수학 수업을 위해 특별하게 구성된 매직믹서 주사위 식 조합 웹앱입니다.
Creative by 예진T

이 프로젝트는 학생들이 스마트폰, 태블릿, PC 등 다양한 환경에서 주사위 눈금 조합을 통해 목표 숫자를 나타내는 수학적 식을 찾을 수 있도록 돕는 실시간 웹 도구입니다.

✨ 주요 기능

음수와 거듭제곱 지원: 중학교 1학년 교육과정에 맞춰 기호 ^ 및 음수를 포함하여 고난도 식까지 자유롭게 구성 가능합니다.

실시간 수식 렌더링: 컴퓨터용 입력인 ^2 또는 *, /를 입력하는 즉시 예쁜 위첨자($x^2$) 및 교과서 기호($\times$, $\div$)의 수학 등식 모양으로 실시간 가시화해 줍니다.

수동 정답 검증: 몸풀기 및 각 레벨에서 사용 제약 조건(사용할 수 없는 수 차단, 주사위의 모든 수를 한 번씩만 썼는지 체크)을 완벽하게 검토해 줍니다.

동적 해법 매칭 알고리즘 (Solver): 주사위를 굴리면 백그라운드 알고리즘이 실시간으로 해당 목표값을 만족시키는 완벽한 예시 식을 탐색하여 placeholder에 가이드해 줍니다.

모바일/태블릿 반응형 드로잉 연습 공간: 학생들의 손글씨 풀이 필기를 지원하는 터치 최적화 화이트보드가 탑재되어 있습니다.

수학 기호 입력 키패드 지원: 입력창을 터치하면 화면 하단에 가상 키패드 툴바가 자동으로 나타나 모바일 터치 입력 환경에서도 ², ³, ^ 같은 거듭제곱을 손쉽게 터치할 수 있습니다.

🚀 깃허브 페이지(GitHub Pages) 무료 배포 방법

이 프로젝트는 단일 HTML 파일(index.html)로 구성되어 있어 서버 설정 없이 단 1분 만에 무료로 배포가 가능합니다.

깃허브 저장소(Repository) 생성

GitHub 계정에 로그인한 뒤, New Repository를 누릅니다.

저장소 이름(예: magic-mixer)을 적고 Create repository를 클릭합니다.

파일 업로드

생성된 저장소에 본 index.html 파일을 업로드(Drag and drop)하고 변경사항을 커밋(Commit changes)합니다.

GitHub Pages 활성화

저장소 상단 메뉴의 Settings (톱니바퀴 아이콘)를 클릭합니다.

왼쪽 메뉴에서 Pages를 선택합니다.

Build and deployment 아래의 Branch 설정을 None에서 main(또는 master)으로 변경하고, 우측의 폴더 경로는 / (root) 상태 그대로 유지한 뒤 Save를 누릅니다.

접속 링크 생성 완료

약 30초~1분 후 상단에 배포 성공 메시지와 함께 수업용 주소(https://<깃허브ID>.github.io/magic-mixer/)가 생성됩니다. 이 주소를 학생들에게 공유하여 수업을 진행하세요!
